# Reglas de Grabador Universitario

## Costo obligatorio de uso: USD 0.00
- No exigir suscripciones, tarjetas, créditos, ni API comerciales de pago.
- No enviar audios a terceros sin acción/consentimiento explícito.
- Grabación y conservación del audio funcionan sin conexión.
- Transcripción local: únicamente mediante motor/modelos gratuitos y abiertos instalados con consentimiento del usuario.
- Wi-Fi con internet: procesamiento en línea solo si existe proveedor gratuito configurado y el usuario lo autoriza; nunca asumir que la red implica consentimiento de subir audio.
- Datos móviles: no usar para procesamiento en línea de forma predeterminada.
- Resumen automático: generar tras transcripción solo cuando haya motor disponible; de lo contrario dejar pendiente.
- Ante ausencia de motor, memoria, batería o conectividad suficiente: mantener audio y marcas, mostrar estado pendiente; no fingir éxito.
- Antes de añadir funciones, compilar y verificar APK en GitHub Actions.
